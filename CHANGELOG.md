# Changelog

## 0.1.0 — Unreleased

- Unified the interface into Home and My Space. Existing topic, Idea and history capabilities remain available.
- Added guest access to real official RSS excerpts, editable natural-language search and time filters.
- Kept personal bookmarks, preferences, ideas and AI history isolated with Supabase RLS.
- Required login for real AI calls; missing configuration explicitly displays “AI 未配置”. Examples remain labeled.
- Added source URL/DNS restrictions, bounded RSS requests and public response field filtering.
- Replaced the inherited local development database password with generated private credentials.
- Prepared bilingual documentation, license metadata inventory, CI, issue templates and a draft release.

Source publication does not include a hosted deployment or GitHub Release. Payments, automatic delivery and complex agents are not implemented.

## Previous local development

The existing V1.1 MVP and Windows/DeepSeek work are preserved in Git history. V0.1 is the first proposed public milestone, not a claim that the previous implementation was discarded.
