# 技术架构

界面只有两个主工作区：首页 `/` 与我的空间 `/space`。旧工作区地址重定向，能力继续保留；`/demo` 为明确标注的固定示例；`/pricing` 现转到预览页。下文的套餐与订阅表用于服务端额度保护，不代表前台仍有 Pro 推广或启用了支付。

## 请求与数据流

浏览器 → Next.js App Router / SSR 会话 → 身份与输入校验 → 用户作用域 Supabase 查询；受信采集、公开字段投影、绑定当前用户的偏好写入、额度事务和账户删除使用服务角色。服务角色模块含 `server-only`，不进入客户端。

首页自然语言搜索无需登录，规则解析不调用模型，生成可编辑过滤配置；保存主题时仍经登录后确认写 topics。刷新只读取数据库中的可信目录，并经代码中的精确 URL 白名单再次验证。客户端无法添加来源。

## 数据分类

- 公共：sources、articles、article_sources。文章按标准化 URL 唯一，支持跨主题和跨用户复用；数据库匿名角色不可直读，游客经 `/api/public/feed` 获取固定来源、最近七天的有限公开投影；已登录用户的直接数据库查询仍遵守历史窗口。
- 私人：profiles、subscriptions、topics、topic_articles、saved_articles、ideas、ai_analyses、usage_records。直接数据库访问也受所有权 RLS 限制。
- 运行：monitoring_runs、ai_operations；分别记录状态、错误、耗时所需时间戳和 AI 幂等、模型、参数、Token、估算成本。
- 配置与事件：plan_limits 是套餐唯一可信配置；product_events 只记事件名、用户 ID 和时间，不存文章或 Idea 内容。迁移记录表不暴露给普通用户。

浏览器只能写自己的主题、Idea 和收藏；不能写套餐、使用量、文章、AI 结果或运行日志。主题关联沿 topics 所有权检查，跨用户关系不能被访问。删除账户由服务端 Auth 管理 API 触发，外键级联清理私人数据。删除 Idea 也清理对应分析，额度审计记录保留到删除账户。

## 采集边界

仅支持 https://github.blog/feed/，不接受任意 URL。解析 DNS 时拒绝任意内网/本机结果，DNS 两秒截止。禁止重定向，HTTP 十秒超时，2MB 响应限制，100 条上限；禁止 XML 外部实体声明，CDATA 中的 HTML 声明按普通内容处理。只保存最多 800 字符的来源摘要，不保存采集到的全文；展示时由 React 转义，原文链接仅允许 HTTP(S)。

发布时间、来源更新时间、抓取时间独立保存。事件时间没有可核实依据时保持 NULL；缺失发布时间不进入最新简报。主题时区小时窗口与采集日期范围分别过滤。

数据库唯一约束保障文章与关联幂等。用户刷新间隔一分钟；所有用户对同一来源有全局一秒访问限制。并发限制通过事务锁与数据库时间实施。来源故障保留实际错误，部分成功单独标注；中断采集下一次请求时恢复状态。公开入口有五分钟来源缓存和一分钟尝试间隔，返回响应缓存三十秒；这些不等同分布式负载防护，较大访问量仍需平台防护。

## AI 与成本

AIProvider 是统一接口，目前 OpenAICompatible 调用 chat/completions；模型、版本根地址及服务商标签由管理员环境变量配置。服务端超时 45 秒，输入截断至 16000 字符，最大输出 1800 Token，Zod 校验分析结构。

外部内容被放在独立的 user 消息 JSON 字段中，禁止作为系统指令或调用工具。AI 没有创建主题的权限；UI 只提供待确认建议。

reserve_ai 在用户级事务锁中恢复超过五分钟的中断预留、检查 UTC 当日额度并预留；claim_ai 原子保证重试只发起一次模型请求。settle_ai 原子保存结果、使用记录和状态，失败释放额度。恢复为惰性机制，下一次请求时执行，不伪称有后台调度。

Token 按上游返回值记录；USD 成本仅在配置单价且有 Token 数据时估算，不等同账单。真实 AI 要求登录，匿名服务端返回 401；无 Key 返回明确的 AI 未配置说明，不调用模型、不预留额度。固定示例与真实结果分开，Demo 不写 AI 成功或使用记录。重复请求键复用历史操作；失败请求重试需使用新键。

## UI 与 API

两个工作区共享简洁顶部导航；我的空间内部用平级切换保留收藏、主题、Idea、历史和账号配置，移动端响应式、深色模式和可见焦点。核心 API 在 app/api/[...path]，按 bootstrap、topics、refresh、feeds、saved、ideas、ai、preferences、account 分派；Zod 验证输入和资源 UUID，写接口验证 Origin，请求体限制 128KB，私人响应禁止缓存。

主题上限和套餐限制不依赖浏览器状态。后台查询与公开数据库策略共同限制历史。每日 quota 按 UTC 零点重置，界面有说明。

## 指标

注册、主题创建、刷新成功、AI 成功、采集错误和候补记录可从 product_events 聚合；首次发生时间取每用户相应事件的 MIN(created_at)。采集与 AI 错误率分别从运行日志统计。Token 与估算成本从 ai_operations 聚合。没有接入第三方分析平台或默认外发 Idea 笔记；用户主动请求 Idea 分析时，相应笔记才发送至已配置的模型服务。
