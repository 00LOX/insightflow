## 验证边界

浏览器中的中文分析是明确的测试夹具，不是本轮真实模型输出。现有 DeepSeek 受控验证记录保留，本轮回归没有新增付费 AI 调用。无 Key 验证启动单独的真实生产服务并置空 AI_API_KEY；匿名 AI 由主服务实际返回 401。SSRF 使用 URL/IP/DNS 及响应边界测试，不依赖向真实内网地址发探测请求。

历史中的旧固定本地开发密码占位值已失效但未从历史抹去。扫描不保证识别任意未知秘密，不构成完整供应链、容器或渗透审计。公开前应复核历史或采用审查后的源码快照。

**线上网址、线上登录/双用户隔离、中国大陆线路与真实 iOS Safari 尚未验收。** 等待用户确认托管方案、云端账号授权、Auth/邮件配置后执行；本机通过不等于线上通过。GitHub Actions 仅已配置，尚未在 GitHub 运行。
