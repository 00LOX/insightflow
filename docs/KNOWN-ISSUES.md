# 已知限制与下一步

- 本机已通过 DeepSeek 的受控真实中文解读和 Idea 分析；完整服务商故障矩阵与账单核对尚未完成。价格未配置，金额仍为未知。源码不包含密钥，其他设备需自行配置。
- 当前只接入一个 GitHub 官方博客 RSS，不声称覆盖整个 AI 行业；规则关键词可能筛选出零结果，建议先从宽泛主题开始。
- 计划频率和简报时间只保存，自动调度、后台队列、自动日报发送尚未实现。
- 公开服务上线尚未完成：没有生产域名、SMTP、备份策略、隐私合规审查或支付。不能将本地验收描述为可直接公开运营。
- 额度按 UTC 日计，不随用户时区改变。文章与分析历史由查询和 RLS 隐藏，当前未自动物理清除公共旧文章。
- USD 成本是可选单价估算，缺少单价或 Token 时保持未知；不是服务商账单。成本附加信息在结果结算后记录，后续可收敛到同一事务。
- 只有手动刷新。当前数据库逐条幂等写入适合 MVP；公开来源已加短期缓存与来源锁；实际负载增加后再评估批量写入和任务队列。
- 公共文章的所有权属于原来源；仅保存有限摘要并提供原文。正式运营前需逐一核对资讯来源条款与授权。
- Chromium 的 iPhone/iPad 尺寸仿真通过不等同于真实 iOS Safari 测试；尚未在真实设备和 Safari 上验证。
- 本地运行使用真实 Supabase Auth 与 PostgREST，数据库为轻量官方 PostgreSQL；不是完整 Supabase CLI 服务栈，不含 Storage、Realtime 或 Studio。pgTAP 未在此轻量镜像中安装，使用事务 SQL 断言与双账号 API 测试替代。
- npm 依赖审计不等于完整供应链或容器漏洞审计。所有固定版本未来仍需持续更新。
- 测试邮件与测试账号可能留在当前环境；源码包不包含它们，也不提供默认公用账号密码。

下一步顺序：所有者确认免费部署方案 → 配置云端 Auth 与公开网址 → 线上双账号验收 → 收集首批用户反馈。公开 GitHub 仓库和发布 Release 需要另行确认。本轮不实现自动推送、复杂 Agent 或真实支付。
